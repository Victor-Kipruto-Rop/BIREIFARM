# Birei Farm

Premium public website for Birei Farm, built with Next.js App Router, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Configuration

Copy `.env.example` to `.env.local` and configure the enquiry email provider before using the production enquiry endpoint.

## Project status

Initial scaffold and core public pages are being implemented. Business details and product claims must be verified with the farm owner before launch.
